# Global memory (Codex CLI)

Symlinked to `~/.codex/AGENTS.md` by dotfiles/install.sh — applies to every
project on every machine. Keep it short; project-specific rules belong in each
repo's own AGENTS.md.

## Preferences

- Shell is bash; personal helper scripts live in `$DOTFILES_DIR/scripts`.
- Shared agent skills live in `$DOTFILES_SKILLS_DIR` (symlinked to
  `~/.codex/skills`). Add new reusable skills there, not in one-off repos.
- Prefer small, focused commits with clear messages.
